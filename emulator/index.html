    Export audio

    Renders the song as it is on the FM-1 now into 16-bit, 44.1 kHz WAV files, in a ZIP. Loops: each pattern A-H that has notes, one bar-exact loop each (the reverb tail wraps round, so they loop cleanly in Renoise or any DAW). Loops + stems: the same, plus every track of every pattern alone. Whole song: the arrangement once, with its tail. For Renoise: the notes as a MIDI file (one track each, the arrangement, the tempo and meter) and every track's sound as a sample, with a guide to put them together.
